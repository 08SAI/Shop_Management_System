🛍️ Shop Management System
A user-friendly, GUI-based Shop Management System built with Python's Tkinter library and backed by SQLite for data storage. This project helps small business owners efficiently manage inventory, customers, and sales using a simple yet functional interface.

🚀 Features

👨‍💼 Admin Section
Add new products with price and stock information

Update existing product details

Delete products from the database

View all products in a scrollable list with stock level color indicators:

🔴 Red = Low stock

🟠 Orange = Medium stock

🟢 Green = Ample stock

🧾 Customer Section
Add products to a shopping cart

View or remove items from the cart

Automatically updates stock in the database

Generate a printable bill for the customer

🎨 UI Enhancements
Clean and professional color scheme

Responsive layout for better readability

Organized product view with clear headers and alternating row colors

🛠️ Tech Stack

->Technology	Purpose

->Python	Core programming

->Tkinter	GUI development

->SQLite	Local database
